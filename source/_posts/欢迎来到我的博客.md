## ✨ 功能展示

### 代码高亮

主题支持多种编程语言的代码高亮：

```python
def fibonacci(n):
    """计算斐波那契数列"""
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# 测试
for i in range(10):
    print(f"F({i}) = {fibonacci(i)}")
```

```javascript
// JavaScript 示例
```

### 数学公式 (LaTeX)

主题支持 LaTeX 数学公式渲染：

**行内公式**: 这是一个行内公式 $E = mc^2$，爱因斯坦的质能方程。

**块级公式**:

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

**矩阵**:

$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
\begin{bmatrix}
x \\
y
\end{bmatrix}
=
\begin{bmatrix}
ax + by \\
cx + dy
\end{bmatrix}
$$

**求和公式**:

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

